VIDYA VATI DEVI P.G. COLLEGE, PRAYAGRAJ — WEBSITE

Files:
- index.html: website structure
- school-data.json: college information, courses, campus gallery and leadership details
- style.css: responsive design and page styling
- script.js: loads school-data.json, navigation, back-to-top button and demo enquiry form
- assests/: supplied logo and college photos used on the website

Preview:
1. Open a terminal in this folder.
2. Run `py -m http.server 8000`.
3. Visit `http://localhost:8000` in a browser. The JSON data will not load if index.html is opened directly as a file.
4. Internet is needed for Bootstrap CDN and Google Fonts; the college photos and logo load locally from assests/.
